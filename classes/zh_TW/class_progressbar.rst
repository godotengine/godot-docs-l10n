ProgressBar
===========

**繼承：** :ref:`Range<class_Range>` **<** :ref:`Control<class_Control>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

將百分比視覺化表示的控制項。

.. rst-class:: classref-introduction-group

說明
----

將百分比視覺化表示的控制項。在中央顯示填充百分比。還可以用來顯示尚未確定的進度。如果需要更多填充模式，請改用 :ref:`TextureProgressBar<class_TextureProgressBar>`\ 。
