EditorSceneFormatImporterUFBX
=============================

**實驗性：** This class may be changed or removed in future versions.

**繼承：** :ref:`EditorSceneFormatImporter<class_EditorSceneFormatImporter>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

使用 ufbx 庫匯入 FBX 檔案。

.. rst-class:: classref-introduction-group

說明
----

EditorSceneFormatImporterUFBX 旨在載入 FBX 檔案，並支援從版本 3000 開始的二進位和 ASCII FBX 檔案。該類支援各種 3D 物件型別，例如網格、皮膚、混合形狀、材質和綁定資訊。該類旨在與官方 FBX SDK 功能相同，並支援 FBX 7.4 規範。
