.. _class_CanvasItem:

CanvasItem
==========

**繼承：** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**被繼承：** :ref:`Control<class_Control>`, :ref:`Node2D<class_Node2D>`

2D 空間中所有物件的抽象基底類別。

.. rst-class:: classref-introduction-group

說明
----

2D 空間中所有物件的抽象基底類別。畫布項目以樹狀排列；子節點繼承並擴充其父節點的變換。\ **CanvasItem** 由 :ref:`Control<class_Control>` 擴充為 GUI 相關的節點，由 :ref:`Node2D<class_Node2D>` 擴充為 2D 遊戲物件。

任何 **CanvasItem** 都可以進行繪圖。繪圖時，引擎會呼叫 :ref:`queue_redraw()<class_CanvasItem_method_queue_redraw>`\ ，然後 :ref:`NOTIFICATION_DRAW<class_CanvasItem_constant_NOTIFICATION_DRAW>` 就會在空閒時被接收到以請求重繪。因此，畫布項目不需要每一影格都重繪，這顯著提升了效能。這個類還提供了幾個用於在 **CanvasItem** 上繪圖的函式（見 ``draw_*`` 函式）。不過這些函式都只能在 :ref:`_draw()<class_CanvasItem_private_method__draw>` 及其對應的 :ref:`Object._notification()<class_Object_private_method__notification>` 或連接到 :ref:`draw<class_CanvasItem_signal_draw>` 的方法內使用。

畫布項目在其畫布層上是按樹狀順序繪製的。預設情況下，子項目位於其父項目的上方，因此根 **CanvasItem** 將被畫在所有項目的後面。這種行為可以針對每個畫布項目進行更改。

\ **CanvasItem** 可以隱藏，隱藏時也會隱藏其子項目。通過調整 **CanvasItem** 的各種其它屬性，你還可以調制它的顏色（通過 :ref:`modulate<class_CanvasItem_property_modulate>` 或 :ref:`self_modulate<class_CanvasItem_property_self_modulate>`\ ）、更改 Z 索引、混合模式等。

請注意，變換、調制、可見性等屬性只會傳播至\ *直屬*\ 的 **CanvasItem** 子節點。如果中間有 :ref:`Node<class_Node>`\ 、\ :ref:`AnimationPlayer<class_AnimationPlayer>` 等非 **CanvasItem** 節點，那麼更深層 **CanvasItem** 的位置和 :ref:`modulate<class_CanvasItem_property_modulate>` 鏈就是獨立的了。另見 :ref:`top_level<class_CanvasItem_property_top_level>`\ 。

.. rst-class:: classref-enumeration-constant

紋理過濾從最近的像素讀取並在最近的 2 個多級漸遠紋理之間進行混合（或者如果 :ref:`ProjectSettings.rendering/textures/default_filters/use_nearest_mipmap_filter<class_ProjectSettings_property_rendering/textures/default_filters/use_nearest_mipmap_filter>` 為 ``true``\ ，則使用最近的多級漸遠紋理）。這使得紋理從近處看起來像素化，從遠處看起來平滑。

將此用於可能以低縮放查看的非像素藝術紋理（例如，由於 :ref:`Camera2D<class_Camera2D>` 縮放或精靈縮放），因為多級漸遠紋理對於平滑小於螢幕像素的像素很重要。

將此用於可能以低縮放查看的非像素藝術紋理（例如，由於 :ref:`Camera2D<class_Camera2D>` 縮放或精靈縮放），因為多級漸遠紋理對於平滑小於螢幕像素的像素很重要。

.. _class_CanvasItem_constant_TEXTURE_FILTER_NEAREST_WITH_MIPMAPS_ANISOTROPIC:

.. rst-class:: classref-enumeration-constant

:ref:`TextureFilter<enum_CanvasItem_TextureFilter>` **TEXTURE_FILTER_NEAREST_WITH_MIPMAPS_ANISOTROPIC** = ``5``

紋理過濾從最近的像素讀取並根據表面和相機檢視之間的角度在 2 個多級漸遠紋理之間進行混合（或者如果 :ref:`ProjectSettings.rendering/textures/default_filters/use_nearest_mipmap_filter<class_ProjectSettings_property_rendering/textures/default_filters/use_nearest_mipmap_filter>` 為 ``true``\ ，則使用最近的多級漸遠紋理）。這使得紋理從近處看起來像素化，從遠處看起來平滑。各向異性過濾提高了幾乎與相機位於一條線的表面上的紋理品質，但速度稍慢。各向異性過濾層級可以通過調整 :ref:`ProjectSettings.rendering/textures/default_filters/anisotropic_filtering_level<class_ProjectSettings_property_rendering/textures/default_filters/anisotropic_filtering_level>` 來改變。

\ **注意：**\ 該紋理過濾在 2D 專案中很少有用。\ :ref:`TEXTURE_FILTER_NEAREST_WITH_MIPMAPS<class_CanvasItem_constant_TEXTURE_FILTER_NEAREST_WITH_MIPMAPS>` 在這種情況下通常更合適。

    dst.r = texture.r * modulate.r * modulate.a + dst.r * (1.0 - texture.r * modulate.a);
    dst.g = texture.g * modulate.g * modulate.a + dst.g * (1.0 - texture.g * modulate.a);
    dst.b = texture.b * modulate.b * modulate.a + dst.b * (1.0 - texture.b * modulate.a);
    dst.a = modulate.a + dst.a * (1.0 - modulate.a);

|void| **draw_rect**\ (\ rect\: :ref:`Rect2<class_Rect2>`, color\: :ref:`Color<class_Color>`, filled\: :ref:`bool<class_bool>` = true, width\: :ref:`float<class_float>` = -1.0, antialiased\: :ref:`bool<class_bool>` = false\ ) :ref:`🔗<class_CanvasItem_method_draw_rect>`

繪製一個矩形。如果 ``filled`` 為 ``true``\ ，則矩形將使用指定的 ``color`` 填充。如果 ``filled`` 為 ``false``\ ，則矩形將被繪製為具有指定的 ``color`` 和 ``width`` 的筆划。\ ``rect`` 使用區域空間指定。另見 :ref:`draw_texture_rect()<class_CanvasItem_method_draw_texture_rect>`\ 。

如果 ``antialiased`` 為 ``true``\ ，則半透明的“羽毛”將附加到邊界，使輪廓變得平滑。

\ **注意：**\ ``width`` 只有在 ``filled`` 為 ``false`` 時才有效。

\ **注意：**\ 使用負 ``width`` 繪製的未填充矩形可能不會完美顯示。例如，由於線條的重疊，角可能會缺失或變亮（對於半透明的 ``color``\ ）。

.. _class_CanvasItem_method_is_visible_in_tree:

.. rst-class:: classref-method

:ref:`bool<class_bool>` **is_visible_in_tree**\ (\ ) |const| :ref:`🔗<class_CanvasItem_method_is_visible_in_tree>`

如果節點存在於 :ref:`SceneTree<class_SceneTree>` 中，並且 :ref:`visible<class_CanvasItem_property_visible>` 屬性為 ``true``\ 、所有祖級節點也都可見，則回傳 ``true``\ 。如果存在隱藏的祖級節點，則該節點在場景樹中不可見，因此不會進行繪製（見 :ref:`_draw()<class_CanvasItem_private_method__draw>`\ ）。

父節點派生自 **CanvasItem**\ 、\ :ref:`CanvasLayer<class_CanvasLayer>` 或 :ref:`Window<class_Window>` 時才會進行可見性檢查。如果父節點為其他型別（例如 :ref:`Node<class_Node>`\ 、\ :ref:`AnimationPlayer<class_AnimationPlayer>`\ 、\ :ref:`Node3D<class_Node3D>`\ ），則會當作可見。

\ **注意：**\ 該方法不會考慮 :ref:`visibility_layer<class_CanvasItem_property_visibility_layer>`\ ，因此即便回傳 ``true``\ ，最後也可能不渲染該節點。

.. _class_CanvasItem_method_set_instance_shader_parameter:

.. rst-class:: classref-method

|void| **set_instance_shader_parameter**\ (\ name\: :ref:`StringName<class_StringName>`, value\: :ref:`Variant<class_Variant>`\ ) :ref:`🔗<class_CanvasItem_method_set_instance_shader_parameter>`

設定著色器 Uniform 的值，僅限此實例 (`每實例 Uniform <../tutorials/shaders/shader_reference/shading_language.html#per-instance-uniforms>`__)。另請參閱 :ref:`ShaderMaterial.set_shader_parameter()<class_ShaderMaterial_method_set_shader_parameter>`\ ，以在使用相同 :ref:`ShaderMaterial<class_ShaderMaterial>` 的所有實例上指派 Uniform。

\ **注意：** 著色器 Uniform 若要能夠按每個實例指派，它在著色器程式碼中 *必須* 定義為 ``instance uniform ...``\ ，而非 ``uniform ...``\ 。

\ **注意：** ``name`` 區分大小寫，且必須與程式碼中 Uniform 的名稱完全相符 (而非屬性檢視器中大寫的名稱)。
