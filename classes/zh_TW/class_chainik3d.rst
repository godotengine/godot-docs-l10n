ChainIK3D
=========

**繼承：** :ref:`IKModifier3D<class_IKModifier3D>` **<** :ref:`SkeletonModifier3D<class_SkeletonModifier3D>` **<** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**被繼承：** :ref:`IterateIK3D<class_IterateIK3D>`, :ref:`SplineIK3D<class_SplineIK3D>`

:ref:`SkeletonModifier3D<class_SkeletonModifier3D>` 用於對包含任意數量骨骼的骨骼鏈應用反向動力學。

.. rst-class:: classref-introduction-group

說明
----

:ref:`SkeletonModifier3D<class_SkeletonModifier3D>` 的基底類別，能夠自動根據根骨骼與末端骨骼之間的骨骼生成關節清單。

\ **注意：**\ 該類中的所有方法均接受一個 ``index`` 參數。如果 IK 包含多個條目（例如 ``settings/<index>/root_bone_name``\ ），該參數用於指定應回傳哪條設定清單條目。

設定骨骼鏈的末端骨骼名稱。

\ **注意：** 末端骨骼必須是根骨骼或根骨骼的子骨骼。如果相同，則必須通過 :ref:`set_extend_end_bone()<class_ChainIK3D_method_set_extend_end_bone>` 擴充尾部，以修改該骨骼。

.. rst-class:: classref-item-separator

----

.. _class_ChainIK3D_method_set_extend_end_bone:

.. rst-class:: classref-method

|void| **set_extend_end_bone**\ (\ index\: :ref:`int<class_int>`, enabled\: :ref:`bool<class_bool>`\ ) :ref:`🔗<class_ChainIK3D_method_set_extend_end_bone>`

如果 ``enabled`` 為 ``true``\ ，則會延伸末端骨骼形成尾部。

擴充的尾部設定會分配給關節清單中的最後一個元素。換句話說，如果將 ``enabled`` 設定為 ``false``\ ，則關節清單中最後一個元素的設定對模擬結果沒有影響。
