VideoStreamTheora
=================

**繼承：** :ref:`VideoStream<class_VideoStream>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

:ref:`VideoStream<class_VideoStream>` Ogg Theora 影片的資源。

.. rst-class:: classref-introduction-group

說明
----

:ref:`VideoStream<class_VideoStream>` 資源處理帶有 ``.ogv`` 副檔名的 `Ogg Theora <https://www.theora.org/>`__ 影片格式。Theora 編解碼器在 CPU 上進行解碼。

\ **注意：**\ 雖然 Ogg Theora 影片也可以使用 ``.ogg`` 副檔名，但必須將該副檔名重新命名為 ``.ogv`` 才能在 Godot 中使用這些影片。
