.. _class_String:

String
======

字串內建型別。

.. rst-class:: classref-introduction-group

說明
----

這是內建的字串 Variant 型別（GDScript 使用的就是這個型別）。字串中可以包含任意數量的 Unicode 字元，暴露的方法可用於字串的操作和生成。字串有參照計數，使用寫時複製技術（每次對字串的修改都會回傳新的 **String**\ ），所以傳遞字串的資源損耗很小。

部分字串方法有對應的變體。後綴 ``n`` 的變體（\ :ref:`countn()<class_String_method_countn>`\ 、\ :ref:`findn()<class_String_method_findn>`\ 、\ :ref:`replacen()<class_String_method_replacen>` 等）\ **大小寫不敏感**\ （不區分大寫字元和小寫字元）。前綴 ``r`` 的方法變體（\ :ref:`rfind()<class_String_method_rfind>`\ 、\ :ref:`rsplit()<class_String_method_rsplit>` 等）是逆序的，會從字串末尾開始，而不是從開頭開始。

任意 :ref:`Variant<class_Variant>` 和字串之間的相互轉換見 :ref:`@GlobalScope.str()<class_@GlobalScope_method_str>`\ 、\ :ref:`@GlobalScope.str_to_var()<class_@GlobalScope_method_str_to_var>`\ 、\ :ref:`@GlobalScope.var_to_str()<class_@GlobalScope_method_var_to_str>`\ 。

\ **注意：**\ 在布林語境下，空字串（\ ``""``\ ）的求值結果為 ``false``\ 。否則字串的求值結果始終為 ``true``\ 。

.. note::

	使用 C# 操作此 API 時有顯著差異，詳見 :ref:`doc_c_sharp_differences`。

.. _class_String_method_casecmp_to:

.. rst-class:: classref-method

:ref:`int<class_int>` **casecmp_to**\ (\ to\: :ref:`String<class_String>`\ ) |const| :ref:`🔗<class_String_method_casecmp_to>`

與另一個字串進行區分大小寫的比較。如果小於對方則回傳 ``-1``\ ，大於對方則回傳 ``1``\ ，相等則回傳 ``0``\ 。“小於”和“大於”是由每個字串的 `Unicode 碼點 <https://en.wikipedia.org/wiki/List_of_Unicode_characters>`__ 決定的，這大致對應字母表的順序。

如果字元比較進行到了其中一個字串的末尾，而另一個字串還包含更多字元，那麼長度將成為決定因素：如果本字串比 ``to`` 字串更長，則回傳 ``1``\ ，如果更短則回傳 ``-1``\ 。請注意，空字串的長度始終為 ``0``\ 。

如果想從字串比較中取得一個 :ref:`bool<class_bool>`\ （布林值）結果，請改用 ``==`` 運算符。另請參閱 :ref:`nocasecmp_to()<class_String_method_nocasecmp_to>`\ 、\ :ref:`filecasecmp_to()<class_String_method_filecasecmp_to>` 和 :ref:`naturalcasecmp_to()<class_String_method_naturalcasecmp_to>`\ 。

.. _class_String_method_format:

.. rst-class:: classref-method

:ref:`String<class_String>` **format**\ (\ values\: :ref:`Variant<class_Variant>`, placeholder\: :ref:`String<class_String>` = "{_}"\ ) |const| :ref:`🔗<class_String_method_format>`

對字串進行格式化，會將其中出現的所有 ``placeholder`` 都替換為 ``values`` 中的元素。

\ ``values`` 可以是 :ref:`Dictionary<class_Dictionary>`\ 、\ :ref:`Array<class_Array>` 或 :ref:`Object<class_Object>`\ 。\ ``placeholder`` 中的底線都會事先替換為對應的鍵。陣列元素使用對應的索引作為鍵。

::

    # 輸出“Waiting for Godot 是 Samuel Beckett 的戲劇，Godot 引擎由此得名。”
    var use_array_values = "Waiting for {0} 是 {1} 的戲劇，{0} 引擎由此得名。"
    print(use_array_values.format(["Godot", "Samuel Beckett"]))

    # 輸出“第 42 號使用者是 Godot。”
    print("第 {id} 號使用者是 {name}。".format({"id": 42, "name": "Godot"}))

當 ``values`` 為 :ref:`Array<class_Array>` 時還會執行一些額外的處理。如果 ``placeholder`` 不包含底線，則 ``values`` 陣列的元素將用於按順序替換出現的佔位符；如果 ``values`` 的元素也是包含兩個元素的陣列，則會被解釋為鍵值對。

::

    # 輸出“第 42 號使用者是 Godot。”
    print("第 {} 號使用者是 {}。".format([42, "Godot"], "{}"))
    print("第 {id} 號使用者是 {name}。".format([["id", 42], ["name", "Godot"]]))

傳入 :ref:`Object<class_Object>` 時，會將 :ref:`Object.get_property_list()<class_Object_method_get_property_list>` 中的屬性名稱用作鍵。

::

    # 輸出“可見 true，位置 (0, 0)”
    var node = Node2D.new()
    print("可見 {visible}，位置 {position}".format(node))

另見 :doc:`GDScript 格式化字串 <../tutorials/scripting/gdscript/gdscript_format_string>`\ 教學。

\ **注意：**\ 會依序針對 ``values`` 的每個元素進行預留位置替換，\ **並非**\ 同時完成。因此插入的元素中如果包含其他佔位符，就可能在下一次替換時發生改變。這是一把雙刃劍，常會導致預料之外的結果。除非必要，請確保 ``values`` 的元素中不包含佔位符。

::

    print("{0} {1}".format(["{1}", "x"]))           # 輸出“x x”
    print("{0} {1}".format(["x", "{0}"]))           # 輸出“x {0}”
    print("{a} {b}".format({"a": "{b}", "b": "c"})) # 輸出“c c”
    print("{a} {b}".format({"b": "c", "a": "{b}"})) # 輸出“{b} c”

\ **注意：**\ 在 C# 中推薦改為\ `使用「$」進行字串插值 <https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/tokens/interpolated>`__\ 。

.. _class_String_method_naturalcasecmp_to:

.. rst-class:: classref-method

:ref:`int<class_int>` **naturalcasecmp_to**\ (\ to\: :ref:`String<class_String>`\ ) |const| :ref:`🔗<class_String_method_naturalcasecmp_to>`

與另一個字串進行\ **區分大小寫**\ 的 *自然順序* 比較。如果小於對方則回傳 ``-1``\ ，大於對方則回傳 ``1``\ ，相等則回傳 ``0``\ 。“小於”和“大於”是由每個字串的 `Unicode 碼點 <https://en.wikipedia.org/wiki/List_of_Unicode_characters>`__ 決定的，這大致對應字母表的順序。

在進行排序時，自然順序比較會將數字序列作為一個整體數值來排序（這通常更符合人們的預期），而不是單純按單個字元的碼點來排。因此，排序後的數字字串序列會是 ``["1", "2", "3", ...]``\ ，而不會是 ``["1", "10", "2", "3", ...]``\ 。

如果字元比較進行到了其中一個字串的末尾，而另一個字串還包含更多字元，那麼長度將成為決定因素：如果本字串比 ``to`` 字串更長，則回傳 ``1``\ ，如果更短則回傳 ``-1``\ 。請注意，空字串的長度始終為 ``0``\ 。

如果想從字串比較中取得一個 :ref:`bool<class_bool>`\ （布林值）結果，請改用 ``==`` 運算符。另請參閱 :ref:`naturalnocasecmp_to()<class_String_method_naturalnocasecmp_to>`\ 、\ :ref:`filecasecmp_to()<class_String_method_filecasecmp_to>` 和 :ref:`nocasecmp_to()<class_String_method_nocasecmp_to>`\ 。

使用自然順序進行排序時，會和常見預期一樣將連續的數字進行組合，而不是一個個數字進行比較。排序後的數列為 ``["1", "2", "3", ...]`` 而不是 ``["1", "10", "2", "3", ...]``\ 。

進行字元比較時，如果其中一個字串已到達末尾，而另一個字串中還有後續字元，則會使用長度作為決定因素：如果該字串比 ``to`` 字串長則回傳 ``1``\ ，短則回傳 ``-1``\ 。請注意，空字串的長度始終為 ``0``\ 。

.. _class_String_method_num:

.. rst-class:: classref-method

:ref:`String<class_String>` **num**\ (\ number\: :ref:`float<class_float>`, decimals\: :ref:`int<class_int>` = -1\ ) |static| :ref:`🔗<class_String_method_num>`

將 :ref:`float<class_float>` 轉換為十進位小數的字串表示，小數點位數由 ``decimals`` 指定。

如果 ``decimals`` 為預設的 ``-1``\ ，該字串表示可能最多只有 14 位元有效數字，小數點前的數字優先於小數點後的數字。

該字串中不包含後綴的零。最後一位數字會四捨五入，而不是截斷。

::

    String.num(3.141593)     # 回傳 "3.141593"
    String.num(3.141593, 3)  # 回傳 "3.142"
    String.num(3.14159300)   # 回傳 "3.141593"

    # 此處的最後一位數字會進位，
    # 數字位數會減少，因為後綴的零會被移除：
    String.num(42.129999, 5) # 回傳 "42.13"

    # 如果沒有指定 `decimals`，最大有效位數為 14：
    String.num(-0.0000012345432123454321)     # 回傳 "-0.00000123454321"
    String.num(-10000.0000012345432123454321) # 回傳 "-10000.0000012345"

.. _class_String_method_split:

:ref:`PackedStringArray<class_PackedStringArray>` **split**\ (\ delimiter\: :ref:`String<class_String>` = "", allow_empty\: :ref:`bool<class_bool>` = true, maxsplit\: :ref:`int<class_int>` = 0\ ) |const| :ref:`🔗<class_String_method_split>`

使用分隔符 ``delimiter`` 將該字串進行拆分，回傳子字串陣列。如果 ``delimiter`` 為空，則子串為單個字元。這個方法與 :ref:`join()<class_String_method_join>` 相對。

.. tabs::

 .. code-tab:: gdscript

    var some_array = "One,Two,Three,Four".split(",", true, 2)

    print(some_array.size()) # 輸出 3
    print(some_array[0])     # 輸出“One”
    print(some_array[1])     # 輸出“Two”
    print(some_array[2])     # 輸出“Three,Four”

 .. code-tab:: csharp

    // C# 的 `Split()` 不支援 `maxsplit` 參數。

    GD.Print(someArray[1]); // 輸出“Two”
    GD.Print(someArray[2]); // 輸出“Three,Four”

.. _class_String_operator_idx_int:

.. rst-class:: classref-operator

:ref:`String<class_String>` **operator []**\ (\ index\: :ref:`int<class_int>`\ ) :ref:`🔗<class_String_operator_idx_int>`

返回只包含索引為 ``index`` 的字元的新 **String**\ 。索引從 ``0`` 開始。如果 ``index`` 大於等於 ``0``\ ，則字元是從該字串的開頭開始取得的。如果 ``index`` 為負，則從末尾開始取得。越界存取字串會導致運作時錯誤，從編輯器中運作時會將專案暫停。
