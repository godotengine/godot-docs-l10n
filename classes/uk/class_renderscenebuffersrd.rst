RenderSceneBuffersRD
====================

**Успадковує:** :ref:`RenderSceneBuffers<class_RenderSceneBuffers>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Рендерна сцена буферна реалізація для рендерингуDevice на основі рендерингу.

.. rst-class:: classref-introduction-group

Опис
--------

Цей об'єкт керує всіма буферами 3D-рендерингу для рендерерів на основі пристроїв рендерингу. Екземпляр цього об'єкта створюється для кожного вікна перегляду, в якому ввімкнено 3D-рендеринг. Див. також :ref:`RenderSceneBuffers<class_RenderSceneBuffers>`.

Усі буфери організовані в **контексти**. Контекст за замовчуванням називається **render_buffers** і може містити, серед іншого, буфер кольору, буфер глибини, буфери швидкості, карту щільності VRS та варіанти MSAA цих буферів.

Буфери гарантовано існують лише під час рендерингу вікна перегляду.

\ **Примітка:** Це внутрішній об'єкт сервера рендерингу. Не створюйте екземпляр цього класу зі скрипта.
