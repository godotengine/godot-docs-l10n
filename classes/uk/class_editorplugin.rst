EditorPlugin
============

**Успадковує:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Успадковано від:** :ref:`GridMapEditorPlugin<class_GridMapEditorPlugin>`

Використовується редактором для розширення його функціональності.

.. rst-class:: classref-introduction-group

Опис
--------

Плагіни використовуються редактором для розширення функціональності. Найпоширенішими типами плагінів є ті, які редагують дану вершину або тип ресурсу, імпорт плагінів і експорт плагінів. Дивись також :ref:`EditorScript<class_EditorScript>`, щоб додати функції до редактора.

\ **Примітка:** Деякі імена в цьому класі містять "лівий" або "право" (наприклад, :ref:`DOCK_SLOT_LEFT_UL<class_EditorPlugin_constant_DOCK_SLOT_LEFT_UL>`). Ці API припускають ліву версію, і будуть повернені назад при використанні правого вліво макета. Ці імена зберігаються з причин сумісності.

        else: 
            return "Сцена %s має зміни з MyCustomPlugin. Зберегти перед закриттям?" % for_scene.get_file()
