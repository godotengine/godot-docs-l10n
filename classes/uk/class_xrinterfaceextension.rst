XRInterfaceExtension
====================

**Успадковує:** :ref:`XRInterface<class_XRInterface>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Базовий клас для розширення інтерфейсу XR (плугіни).

.. rst-class:: classref-introduction-group

Опис
--------

Зовнішні плагіни інтерфейсу XR повинні успадкуватися від цього класу.

Викликається, якщо це наш основний **XRInterfaceExtension**, перш ніж ми почнемо обробку :ref:`Viewport<class_Viewport>` для кожного активного XR :ref:`Viewport<class_Viewport>`, повертає ``true``, якщо цей viewport має бути відрендерений.
