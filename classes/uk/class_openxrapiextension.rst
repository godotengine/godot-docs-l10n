OpenXRAPIExtension
==================

**Успадковує:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Зробіть API OpenXR, доступний для GDExtension.

.. rst-class:: classref-introduction-group

Опис
--------

**OpenXRAPIExtension** робить OpenXR доступним для GDExtension. За допомогою методу OpenXR API до GDExtension через :ref:`get_instance_proc_addr()<class_OpenXRAPIExtension_method_get_instance_proc_addr>` та екземпляр OpenXR через :ref:`get_instance()<class_OpenXRAPIExtension_method_get_instance>`.

Також передбачено методи запиту стану ініціалізації OpenXR, а також методи помічника для зручності використання API з GDExtension.
