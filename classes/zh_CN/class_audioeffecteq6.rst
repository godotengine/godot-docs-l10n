AudioEffectEQ6
==============

**继承：** :ref:`AudioEffectEQ<class_AudioEffectEQ>` **<** :ref:`AudioEffect<class_AudioEffect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Adds a 6-band equalizer audio effect to an audio bus.

Gives you control over frequencies from 32 Hz to 10000 Hz. Each frequency can be modulated between -60/+24 dB.

.. rst-class:: classref-introduction-group

描述
----

频段：

频段 1：32 Hz

频段 2：100 Hz

频段 3：320 Hz

频段 4：1000 Hz

频段 5：3200 Hz

频段 6：10000 Hz

另见 :ref:`AudioEffectEQ<class_AudioEffectEQ>`\ 、\ :ref:`AudioEffectEQ10<class_AudioEffectEQ10>`\ 、\ :ref:`AudioEffectEQ21<class_AudioEffectEQ21>`\ 。
