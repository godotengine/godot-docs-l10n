AnimationPlayer
===============

**Наследует:** :ref:`AnimationMixer<class_AnimationMixer>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Узел, используемый для воспроизведения анимации.

.. rst-class:: classref-introduction-group

Описание
----------------

Анимационный проигрыватель используется для воспроизведения анимаций общего назначения. Он содержит словарь ресурсов :ref:`AnimationLibrary<class_AnimationLibrary>` и настраиваемые времена смешивания между анимационными переходами.

Некоторые методы и свойства используют один ключ для прямой ссылки на анимацию. Эти ключи форматируются как ключ для библиотеки, за которым следует косая черта, затем ключ для анимации в библиотеке, например ``"movement/run"``. Если ключ библиотеки представляет собой пустую строку (известную как библиотека по умолчанию), косая черта опускается, являясь тем же ключом, который используется библиотекой.

\ **AnimationPlayer** лучше подходит, чем :ref:`Tween<class_Tween>`, для более сложных анимаций, например, с нетривиальными временными интервалами. Его также можно использовать вместо :ref:`Tween<class_Tween>`, если редактор трека анимации удобнее, чем делать это в коде.

Обновление целевых свойств анимаций происходит в кадре процесса (process).

.. _class_AnimationPlayer_property_current_animation:

- |void| **set_current_animation**\ (\ value\: :ref:`StringName<class_StringName>`\ )

Ключ текущей воспроизводимой анимации. Если анимация не воспроизводится, значением свойства является пустая строка. Изменение этого значения не перезапускает анимацию. См. :ref:`play()<class_AnimationPlayer_method_play>` для получения дополнительной информации о воспроизведении анимаций.

.. _class_AnimationPlayer_property_movie_quit_on_finish:

.. rst-class:: classref-property

:ref:`bool<class_bool>` **movie_quit_on_finish** = ``false`` :ref:`🔗<class_AnimationPlayer_property_movie_quit_on_finish>`

.. rst-class:: classref-property-setget

- |void| **set_movie_quit_on_finish_enabled**\ (\ value\: :ref:`bool<class_bool>`\ )
- :ref:`bool<class_bool>` **is_movie_quit_on_finish_enabled**\ (\ )

Если ``true`` и движок работает в режиме Movie Maker (см. :ref:`MovieWriter<class_MovieWriter>`), выходит из движка с помощью :ref:`SceneTree.quit()<class_SceneTree_method_quit>`, как только анимация завершит воспроизведение в этом **AnimationPlayer**. \ **Примечание:** Это подчиняется той же логике, что и сигнал :ref:`AnimationMixer.animation_finished<class_AnimationMixer_signal_animation_finished>`, поэтому он не выйдет из движка, если анимация установлена как циклическая.

.. _class_AnimationPlayer_property_playback_auto_capture:

.. rst-class:: classref-property

:ref:`bool<class_bool>` **playback_auto_capture** = ``true`` :ref:`🔗<class_AnimationPlayer_property_playback_auto_capture>`

.. rst-class:: classref-property-setget

- |void| **set_auto_capture**\ (\ value\: :ref:`bool<class_bool>`\ )

Если ``true``, выполняет :ref:`AnimationMixer.capture()<class_AnimationMixer_method_capture>` перед воспроизведением автоматически. \ **Примечание:** Интерполяция захвата выполняется только в том случае, если анимация содержит трек захвата. См. также :ref:`Animation.UPDATE_CAPTURE<class_Animation_constant_UPDATE_CAPTURE>`.

.. _class_AnimationPlayer_method_play:

.. rst-class:: classref-method

|void| **play**\ (\ name\: :ref:`StringName<class_StringName>` = &"", custom_blend\: :ref:`float<class_float>` = -1, custom_speed\: :ref:`float<class_float>` = 1.0, from_end\: :ref:`bool<class_bool>` = false\ ) :ref:`🔗<class_AnimationPlayer_method_play>`

Воспроизводит анимацию с ключом ``name``. Можно задать пользовательское время смешивания и скорость.

Параметр ``from_end`` влияет только при переключении на новый трек анимации или на тот же трек, но в начале или конце. Он не влияет на возобновление воспроизведения, которое было приостановлено в середине анимации. Если ``custom_speed`` отрицательный, а ``from_end`` равен ``true``, анимация будет воспроизводиться в обратном направлении (что эквивалентно вызову :ref:`play_backwards()<class_AnimationPlayer_method_play_backwards>`).

\ **AnimationPlayer** отслеживает свою текущую или последнюю воспроизведенную анимацию с помощью :ref:`assigned_animation<class_AnimationPlayer_property_assigned_animation>`. Если этот метод вызывается с той же анимацией ``name`` или без параметра ``name``, назначенная анимация возобновит воспроизведение, если она была приостановлена.

\ **Примечание:** Анимация будет обновлена при следующей обработке **AnimationPlayer**. Если другие переменные обновляются одновременно с этим вызовом, они могут обновиться слишком рано. Чтобы выполнить обновление немедленно, вызовите ``advance(0)``.

|void| **play_with_capture**\ (\ name\: :ref:`StringName<class_StringName>` = &"", duration\: :ref:`float<class_float>` = -1.0, custom_blend\: :ref:`float<class_float>` = -1, custom_speed\: :ref:`float<class_float>` = 1.0, from_end\: :ref:`bool<class_bool>` = false, trans_type\: :ref:`TransitionType<enum_Tween_TransitionType>` = 0, ease_type\: :ref:`EaseType<enum_Tween_EaseType>` = 0\ ) :ref:`🔗<class_AnimationPlayer_method_play_with_capture>`

Вы можете использовать этот метод для использования более подробных параметров захвата, чем те, которые выполняются :ref:`playback_auto_capture<class_AnimationPlayer_property_playback_auto_capture>`. ::

    capture(name, duration, trans_type, ease_type)
    play(name, custom_blend, custom_speed, from_end)

Если ``name`` пусто, он указывает :ref:`assignment_animation<class_AnimationPlayer_property_assignment_animation>`.

Если ``duration`` отрицательное значение, длительность устанавливается на интервал между текущей позицией и первым ключом, когда ``from_end`` равен ``true``, вместо этого используется интервал между текущей позицией и последним ключом.

.. rst-class:: classref-method

|void| **set_section_with_markers**\ (\ start_marker\: :ref:`StringName<class_StringName>` = &"", end_marker\: :ref:`StringName<class_StringName>` = &""\ ) :ref:`🔗<class_AnimationPlayer_method_set_section_with_markers>`

Изменяет начальный и конечный маркеры воспроизводимого раздела. Текущая позиция воспроизведения будет зафиксирована в новом разделе. См. также :ref:`play_section_with_markers()<class_AnimationPlayer_method_play_section_with_markers>`.

Если аргумент пустой, раздел использует начало или конец анимации. Если оба пусты, это означает, что раздел не установлен.

.. _class_AnimationPlayer_method_stop:

.. rst-class:: classref-method

|void| **stop**\ (\ keep_state\: :ref:`bool<class_bool>` = false\ ) :ref:`🔗<class_AnimationPlayer_method_stop>`

Останавливает текущую воспроизводимую анимацию. Позиция анимации сбрасывается на ``0``, а ``custom_speed`` сбрасывается на ``1.0``. См. также :ref:`pause()<class_AnimationPlayer_method_pause>`.

Если ``keep_state`` равен ``true``, состояние анимации визуально не обновляется.

\ **Примечание:** Метод / аудио / дорожки воспроизведения анимации не будут обрабатываться этим методом.
