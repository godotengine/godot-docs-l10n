Skeleton3D
==========

**Наследует:** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Узел, содержащий иерархию костей, используемый для создания трехмерной скелетной анимации.

.. rst-class:: classref-introduction-group

Описание
----------------

**Skeleton3D** предоставляет интерфейс для управления иерархией костей, включая позу, покой и анимацию (см. :ref:`Animation<class_Animation>`). Он также может использовать физику ragdoll.

Общее преобразование кости относительно скелета определяется позой кости. Остаток кости определяет начальное преобразование позы кости.

Обратите внимание, что «глобальная поза» ниже относится к общему преобразованию кости относительно скелета, поэтому это не фактическое глобальное/мировое преобразование кости.

.. _class_Skeleton3D_property_animate_physical_bones:

.. rst-class:: classref-property

:ref:`bool<class_bool>` **animate_physical_bones** = ``true`` :ref:`🔗<class_Skeleton3D_property_animate_physical_bones>`

.. rst-class:: classref-property-setget

- |void| **set_animate_physical_bones**\ (\ value\: :ref:`bool<class_bool>`\ )
- :ref:`bool<class_bool>` **get_animate_physical_bones**\ (\ )

**Устарело:** Это свойство может быть изменено или удалено в будущих версиях.

Если вы следуете рекомендуемому рабочему процессу и явно указываете :ref:`PhysicalBoneSimulator3D<class_PhysicalBoneSimulator3D>` как дочерний элемент **Skeleton3D**, вы можете контролировать, будет ли он затронут raycasting без запуска :ref:`physical_bones_start_simulation()<class_Skeleton3D_method_physical_bones_start_simulation>`, с помощью его :ref:`SkeletonModifier3D.active<class_SkeletonModifier3D_property_active>`.

Однако для старых (устаревших) конфигураций **Skeleton3D** имеет внутренний виртуальный :ref:`PhysicalBoneSimulator3D<class_PhysicalBoneSimulator3D>` для совместимости. Это свойство управляет внутренним виртуальным :ref:`PhysicalBoneSimulator3D<class_PhysicalBoneSimulator3D>` :ref:`SkeletonModifier3D.active<class_SkeletonModifier3D_property_active>`.

:ref:`int<class_int>` **add_bone**\ (\ name\: :ref:`String<class_String>`\ ) :ref:`🔗<class_Skeleton3D_method_add_bone>`

.. rst-class:: classref-method

|void| **advance**\ (\ delta\: :ref:`float<class_float>`\ ) :ref:`🔗<class_Skeleton3D_method_advance>`
