RenderSceneDataRD
=================

**Наследует:** :ref:`RenderSceneData<class_RenderSceneData>` **<** :ref:`Object<class_Object>`

Реализация данных рендеринга сцены для рендереров на основе RenderingDevice.

.. rst-class:: classref-introduction-group

Описание
----------------

Объект содержит данные сцены, относящиеся к рендерингу одного кадра в окне просмотра. См. также :ref:`RenderSceneData<class_RenderSceneData>`, :ref:`RenderData<class_RenderData>` и :ref:`RenderDataRD<class_RenderDataRD>`.

\ **Примечание:** Это внутренний объект сервера рендеринга. Не создавайте экземпляр этого класса из скрипта.
