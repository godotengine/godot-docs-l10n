MeshInstance2D
==============

**Наследует:** :ref:`Node2D<class_Node2D>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Узел, используемый для отображения :ref:`Mesh<class_Mesh>` в 2D.

.. rst-class:: classref-introduction-group

Описание
----------------

Узел, используемый для отображения :ref:`Mesh<class_Mesh>` в 2D. Это может быть быстрее при рендеринге по сравнению с отображением узла :ref:`Sprite2D<class_Sprite2D>` с большими прозрачными областями, особенно если узел занимает много места на экране при высоком разрешении области просмотра. Это связано с тем, что использование сетки, разработанной для соответствия непрозрачным областям спрайта, снизит коэффициент заполнения графического процессора (за счет увеличения использования вершинной обработки).

Если :ref:`Mesh<class_Mesh>` необходимо создать более тысячи раз близко друг к другу, рассмотрите возможность использования :ref:`MultiMesh<class_MultiMesh>` в :ref:`MultiMeshInstance2D<class_MultiMeshInstance2D>`.



\ **MeshInstance2D** можно создать из существующего :ref:`Sprite2D<class_Sprite2D>` с помощью инструмента на панели инструментов редактора. Выберите узел :ref:`Sprite2D<class_Sprite2D>`, затем выберите **Sprite2D > Преобразовать в MeshInstance2D** в верхней части области просмотра 2D-редактора.
