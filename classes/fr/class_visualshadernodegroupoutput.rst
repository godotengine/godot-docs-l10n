VisualShaderNodeGroupOutput
===========================

**Hérite de :** :ref:`VisualShaderNode<class_VisualShaderNode>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Represents the output ports of a :ref:`VisualShaderGroup<class_VisualShaderGroup>` within its graph.

.. rst-class:: classref-introduction-group

Description
-----------

This node is automatically created inside each :ref:`VisualShaderGroup<class_VisualShaderGroup>`. It has no output ports and its input ports correspond to the output ports defined on the parent :ref:`VisualShaderGroup<class_VisualShaderGroup>`.
