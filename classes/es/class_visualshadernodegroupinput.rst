VisualShaderNodeGroupInput
==========================

**Hereda:** :ref:`VisualShaderNode<class_VisualShaderNode>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Represents the input ports of a :ref:`VisualShaderGroup<class_VisualShaderGroup>` within its graph.

.. rst-class:: classref-introduction-group

Descripción
----------------------

This node is automatically created inside each :ref:`VisualShaderGroup<class_VisualShaderGroup>`. It has no input ports and its output ports correspond to the input ports defined on the parent :ref:`VisualShaderGroup<class_VisualShaderGroup>`.
