ImageFormatLoader
=================

**Hereda:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Heredado por:** :ref:`ImageFormatLoaderExtension<class_ImageFormatLoaderExtension>`

Clase base para añadir soporte para formatos de imagen específicos.

.. rst-class:: classref-introduction-group

Descripción
----------------------

El motor soporta múltiples formatos de imagen de serie (PNG, SVG, JPEG, WebP, por nombrar algunos), pero puedes optar por implementar soporte para formatos de imagen adicionales extendiendo :ref:`ImageFormatLoaderExtension<class_ImageFormatLoaderExtension>`.
