HSeparator
==========

**Hereda:** :ref:`Separator<class_Separator>` **<** :ref:`Control<class_Control>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Una línea horizontal utilizada para separar otros controles.

.. rst-class:: classref-introduction-group

Descripción
----------------------

Un separador horizontal usado para separar otros controles que están organizados **verticalmente**. **HSeparator** es puramente visual y normalmente se dibuja como un :ref:`StyleBoxLine<class_StyleBoxLine>`.
